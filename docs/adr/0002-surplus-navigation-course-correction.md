# Surplus Navigation pays down Course Error (playtest-driven)

Headless auto-play of the first implementation (300–400 seeded games per policy) showed Course Error
was the dominant loss cause by far: ~75% of games ended CONTACT LOST — TRAJECTORY MISSED even for a
policy that uses crew abilities and escalates to Sacrifice, because ~7 crisis cards add Course Error
against a hard budget of 3, and Control/Compute dual requirements are frequently unmeetable from a
random 5-of-18 system draw.

**Decision:** at crisis resolution, Navigation capability contributed beyond the requirement
(surplus ≥ 3) reduces Course Error by 1. This is not in the design PDF — it gives the Navigation
Computer a course-correction role outside Navigation crises, mirrors the existing surplus-Cooling /
Heat rule structurally, and turns course management into a spend-capability-now decision, which is
the game's core mechanic. RE-ENTRY VECTOR TRIM's failure was also softened from Course Error +2 to
+1 plus one random system damaged.

**Consequences:** with this rule, simulated policies win ~15% (naive, no course management) to ~58%
(course-aware play, still without using repair/cannibalise) — the intended hard-but-winnable band.
If the game later proves too easy for expert players, tighten this rule (surplus ≥ 4) before
touching crisis requirements.
